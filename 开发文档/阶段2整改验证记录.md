## 实现概述

### S2-F01 `dbc33cf`

`copy_dir(from, to)` 已删除。新命令 `import_custom_model` 只接受源目录和资源 ID。调用窗口取自 Tauri 注入的 `WebviewWindow`，只允许 `preference`。目标由后端用应用数据目录拼成 `custom-models/<资源ID>`，资源 ID 只能是一段字母、数字、下划线或连字符。

复制前会确认源是真实目录、顶层有 `.model3.json`，并拒绝源本身或目录树中的符号链接。源和目标互相包含时拒绝。目标已存在则不覆盖。复制中途失败时，只删除本次新建的那个子目录。前端只有在命令成功后才把返回路径写入模型列表。

同时打开了应用命令 ACL。未列入清单的自定义命令会被拒绝，因此 `invoke_handler` 里的命令都写进了 `build.rs`，并按窗口拆开授权。

| 命令                                                                      | 允许窗口         | 后端是否再校验                                                     |
| ------------------------------------------------------------------------- | ---------------- | ------------------------------------------------------------------ |
| `import_custom_model`                                                     | preference       | 是，非 preference 在创建目录前返回                                 |
| `set_ai_key`、`clear_ai_key`                                              | preference       | 是，沿用原有校验                                                   |
| `get_ai_key`、`get_ai_key_status`                                         | chat、preference | 是，main 仍然不能读 Key                                            |
| `start_device_listening`、`start_gamepad_listing`、`stop_gamepad_listing` | main             | 否，只收紧了 ACL。这三个命令原先没有窗口校验，前端也只在主窗口调用 |

`main` 没有因此获得读 Key 或导入模型的权限。自动生成的权限文件在 `src-tauri/permissions/autogenerated/`，已被仓库忽略，由 `build.rs` 在编译时生成。

### S2-F02 `8aae91c`

每次发送或重试在等待 API Key 之前就建立独立的运行对象和 `AbortController`。取消会立刻把 `sending` 设为 false，并中止该对象。Key 之后成功或失败，都不会再调用 AI，也不会改写更新的请求。

问题还没进入消息列表时，取消结果带 `restoreDraft: true`，输入框只在仍然为空时恢复原文。已经有气泡的重试会把原问题标成 `cancelled`，不复制一条。清空会话会增加会话版本并取消旧任务。隐藏聊天只调用 `hideWindow`；页面真正卸载才调用 `cancel()`。

### S2-F03 `0e4fa34`

主窗口按加载代次尝试当前模型，失败后按 `standard`、`keyboard`、`gamepad` 的顺序各试一次未用过的内置模型。成功时才调用 `bindModel`，不重新生成宠物 ID、名字、人格或创建时间。全部失败时 `loadPhase` 为 `error`，`modelReady` 保持 false，主窗口给出重试，设置页遮罩只在 `loading` 时出现。

Live2D 加载经过同一个队列。过期的加载在画出结果前会销毁自己刚放上画布的精灵。回退成功后写回 `currentModel` 的那一次 watcher 会被跳过，避免再开一条恢复链。

## 未验证和限制

- 原生 Tauri 窗口 IPC 没有跑。Tauri 的 mock runtime 不能直接调用带具体 `WebviewWindow` 的命令，所以没有把 JSON 或标签单元测试写成原生 IPC 通过。
- 真实 Live2D 回退、模型导入后的可选加载、隐藏/再打开聊天、退出重启，都没有在桌面应用里操作。
- Windows / Linux 没有运行。符号链接和管道文件清理只在这台 macOS 上测过。
- 导入校验不能排除并发替换目录的竞态。校验和复制之间如果目标被换成符号链接，清理函数会拒绝删除父目录不一致的路径，但不会声称已经防住所有文件系统竞态。
- 取消只保证本机不再采用旧结果。没有承诺服务商已经停止计算或计费。
- 设备监听命令只按窗口收了 ACL，Rust 里没有再做标签校验。
- `docs/完整版方案.html` 仍未跟踪，不属于这三项整改。
